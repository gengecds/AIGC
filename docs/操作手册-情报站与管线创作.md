## 一、管线进度是怎么来的？

前端管线向导通过 SSE 订阅真实管线事件：

- 启动后生成真实 `run_id`，前端以 `run_id=xxx` 订阅 `GET /pipeline/events?run_id=xxx`。
- 后端 `_real_streamer()` 先**回放**该管线已产生的历史事件，再**增量推送**后续的真实 Agent 进度。
- 特殊值 `__demo__` **已被移除**，传它只会被拒绝（400），不再返回任何假数据。

**界面上如何确认是真数据：**
- 运行栏显示金色「真实运行中」标签 → 真实管线。
- 管线停在审核断点时，底部显示「⏸️ 管线等待你确认」。

## 二、情报看板怎么操作（Intel）

情报看板的数据是**真实**的（基于已落盘的 16 个案例 `storage/intel/cases/*.json`），用来「挑选题、建创意」。

### 操作步骤
1. 打开工作台（见第 四 节）。
2. 点顶栏 **「情报站」** 按钮，进入情报看板。
3. 看板展示选题卡片；每张卡片来自一个真实案例的爆款拆解。
4. 选中一条选选题，点击卡片上的**「推入管线」**。
5. 前端会跳转到管线向导，并把 `t=<选题>&auto=1` 写入 URL：
   - `t=选题`：把选题填入创作输入框。
   - `auto=1`：进入页面后**自动**开始真实创作。

> 说明：情报看板本身只负责选题，不会直接生成视频；生成动作由管线向导完成。

### 2.1 一键采集前：先登录一次（之后免登录）
采集脚本通过本地 Chrome（CDP 9222）抓各平台素材，需要账号登录态才能避开风控。为此项目增加了**专用持久浏览器**：用固定数据目录启动 Chrome，**登录态会自动保存**，登录一次后采集自动复用，不再重复登录。

- 采集入口点 **「一键全平台采集」** 时，后端会自动拉起该专用浏览器（`scripts/intel/cdp_chrome.py`）。
- 首次使用的浏览器是**全新空 profile**，需要你现在登录一次抖音 / 小红书 / YouTube：
  1. 打开后面板的 Chrome（底部任务栏，或空白页新标签）。
  2. 在地址栏逐个访问并扫码/账号登录：
     - `https://www.douyin.com/`
     - `https://www.xiaohongshu.com/`
     - `https://www.youtube.com/`
  3. 登录完成后，关不关浏览器都行；**下次点采集会自动复用登录态，不用再登**。

> 脚本：`python scripts/intel/cdp_chrome.py --page douyin`（或 `xiaohongshu` / `youtube`）可手动拉起并直通登录页。
> profile 目录：`storage/intel/chrome-profile`（已被 `.gitignore` 忽略，登录态不会提交进 git）。

## 三、管线创作怎么操作（Pipeline）

### 3.1 想真生成 → 直接开始（必须先启动 ComfyUI）
在管线向导顶部的「真实创作运行栏」：
1. 输入一句话/题材（至少 2 个字）。
2. 选择风格（默认为首选风格）。
3. 点 **「▶ 开始真实创作」**。

或者：
- 从**情报站**点「推入管线」（自动带选题 + 自动开始）。
- 点 **「↻ 恢复进行中」** 找回最近一条仍在运行/等待审核的管线。

### 3.2 真实模式的审核断点（重点）
真实管线会在关键步骤完成后**暂停**，等待人工确认，这就是「审核断点」。它们在：

| 节点 | 断点步骤 |
|:---|:---|
| research_agent（方案） | 步骤 0 · 剧本审查 |
| script_agent（剧本） | 步骤 0 · 剧本审查 |
| storyboard_agent（分镜） | 步骤 1 · 分镜审查 |
| character_agent / image_agent（角色定妆照 / 出图） | 步骤 2 · 角色图审查 |
| video_agent / subtitle_agent（视频 / 字幕） | 步骤 3 · 视频预览 |
| video_compose_agent / audio_agent / publish_agent（合成 / 音频 / 发布） | 步骤 4 · 最终发布 |

此时底部会出现：
- **「确认继续 ⏩」** → 调用 `POST /api/v1/pipeline/approve/{pipeline_id}`，批准放行，管线继续下一步。
- **「拒绝并跳过」** → 调用 `POST /api/v1/pipeline/reject/{pipeline_id}`，跳过该步继续。

> 卡片中间会展示该步骤的产物（剧本 / 分镜 Prompt / 角色图 / 视频预览 / 成片信息），并提示「⏸️ 等待审核：XX已生成，可查看/修改后继续」。

> ⚠️ 重要：**真实模式必须点「确认继续」否则管线会一直卡在断点**。之前 3 条管线卡住，就是因为「继续」此前只做视觉推进、没调真实 `approve`。现已修复接线。

## 五、端到端实操（情报 → 线 → 成片）

1. 启动 ComfyUI + 后端 + 前端（第 四 节）。
2. 打开工作台 → 点「情报站」。
3. 选一张选题卡片 → 点「推入管线」。
4. 管线向导自动填好选题并开始真实创作。
5. 每条管线在方案 / 剧本 / 分镜 / 角色图 / 视频 / 合成 / 发布等节点会**暂停等审核**。
6. 看到「⏸️ 等待审核」时，核对内容，点 **「确认继续 ⏩」**（放行）或 **「拒绝并跳过」**。
7. 直到全部步骤完成，进入「最终发布」，可**导出到 Obsidian** / **下载成片**。

## 六、常见问题（FAQ）

**Q1：管线一直在「等待审核」，再也不动了？**
A：点「确认继续 ⏩」（调用 `/approve`）放行。若之前卡住是因为旧版本「继续」没接接口，现已修复；已卡住的旧管线可点「↻ 恢复进行中」找回，或取消后重建。

**Q2：出图 / 视频环节失败 / 报 `Connection refused`？**
A：ComfyUI 没启动，或端口和 `config.yaml` 的 `comfyui.server_port` 不一致。先启动 ComfyUI 并对齐端口。

**Q3：打开页面看到的进度是真的吗？**
A：是。管线已移除演示模式/`__demo__` 假流，所有进度都是真实 Agent 事件（回放历史 + 增量推送）。运行栏显示金色「真实运行中」标签即为真实管线。

**Q4：情报看板里的选题是编的吗？**
A：不是。它读取 `storage/intel/cases/` 里的真实拆解案例，用 `BenchmarkEngine` 生成选题。看板里点「一键全平台采集」会抓取抖音/小红书/YouTube 真实爆款素材、自动拆解回填，标题取自真实素材而非模板。

**Q5：能不能在向导里直接改内容？**
A：向导允许预览每步产物，但**「确认继续」= 批准原稿放行**（不引入人工修改稿，避免破坏结构化数据）。若需要改剧本/分镜，建议重跑或后续在原生控制台深改。

**Q6：采集要登录吗？能不能只登一次？**
A：要登录态，但**只需一次**。采集用「专用持久浏览器」（固定 `storage/intel/chrome-profile`），首次点采集后分别登录抖音/小红书/YouTube 各一次，之后的采集会自动复用登录态，不再重复登录。若采集提示「未抓到结果（被风控/页面结构变化）」，多半是该平台还没在这个专用浏览器里登录过。

## 七、关键接口速查

| 操作 | 方法 | 路径 |
|:---|:---|:---|
| 启动一条真实管线 | POST | `POST /api/v1/pipeline/run` |
