## 二、需求 1-5 详解（历史已开发内容）

### 1. 自动生成流程升级
**你的原意**：提出需求后不是马上做，而是先收集资料、素材，比较类似成品，再输出完整制作方案，最后才写文案；文案要细、关键词强调。

**已实现**：
- 新增 `research_agent`（第 0 步）：输出结构化「制作方案」JSON——`title / target_audience(目标人群) / style_direction(风格) / narrative_structure(叙事结构) / key_words / render_engine_words(渲染引擎词) / lighting_words(光影词) / camera_words(镜头语言) / copy_points(文案要点) / bgm_mood(BGM情绪) / scene_sounds(场景音效)`
- 新增 `scripts/collect_materials.py`：用本地 Chrome(CDP 9222) 搜抖音/B站类似成品，抓竞品清单+截图落盘 `storage/materials/{关键词}/summary.json`
- `research_agent._find_materials()`：按需求关键词匹配素材，把竞品清单注入 prompt
- 方案新增 `reference_cases` 字段：LLM 归纳竞品亮点/可借鉴处
- 素材可选：无素材时 research 照常纯 LLM 生成，不阻塞管线

**差距**：素材自动收集依赖本地 Chrome(CDP) 启动，未启动时该步自动跳过。

### 2. 前端卡顿修复
**你的原意**：前端输入需求后生成卡住不动，必须处理。

**已解决**（根因 → 修复）：
- 根因：前端 SSE 只监听 `agent_blocked/pipeline_done`，未监听 `agent_start/agent_done` → 卡片不动
- 修复：后端 SSE 全事件广播（`pipeline_start / agent_start / agent_done / agent_fail / agent_blocked / pipeline_done`）+ 前端 4s 运行状态轮询 + 审核弹窗居中置顶 + 生成按钮状态机（排队→执行→审核→完成）
- 额外修复：`_sse_broadcast` 作用域 bug（从 register 内提升到模块级）

### 3. 前端登录系统
**你的原意**：前端登录页，数据库自选，交付成品。

**已实现**：
- 数据库：沿用 SQLite（`storage/ai_drama.db`，零迁移），新增 `users` 表
- 接口：`POST /api/auth/register`、`POST /api/auth/login`、`POST /api/auth/logout`、`GET /api/auth/me`
- 密码：sha256+salt 哈希；token：secrets 随机存库；受保护接口校验 `Authorization: Bearer <token>`
- 前端：登录/注册全屏遮罩，token 存 localStorage，请求自动带 Bearer，未登录拦截

### 4. 视频质量（画面 + 音频）
**你的原意**：视频无声 + 画面走形。方向是「AI 漫剧 + 产品广告」；先出图要符合需求；按需求+图+方案出剧本且每分镜细节确认；从 flac.music.hi.cn 下载 BGM。

**已实现（画面）**：
- 出图尺寸 512 → 768（hi-res fix 后 1024）
- `sd_prompt` 自动追加渲染引擎+光影+摄影参数（35mm/f2.8/浅景深）
- 角色一致性：ControlNet(canny) + IP-Adapter(锁脸) + 稳定 seed，`controlnet_strength` 0.8
- 分镜阶段强制「每镜内容细节」，出图前可预览确认

**已实现（音频）**：
- 音量提升（BGM 0.38 / 环境音 0.12 / 配音 1.25）+ 输出前限幅防爆
- 场景音效层：按分镜内容程序合成（煎锅滋滋/雨声/风声/脚步/车流）
- 多风格 BGM：温馨/激昂/悬疑/清新（按剧情情绪自动选）
- `storage/music/*` 优先使用用户的真人音乐

**⛔ 被阻塞**：真人 BGM 下载（`scripts/music_downloader.py` 已写好，agent-browser 驱动本地 Chrome CDP 9222 访问 flac.music.hi.cn），网站有 CDN 人机验证，当前被风控拦截，解除后即可用；回退到程序合成 BGM 已顶替。

### 5. 集中式工作方式
**已按此执行**：先梳理 → 开发 → 统一测试 → 完善。

### 6. 内容必须量化（分层叠加法落地）
**问题根因**（已定位，非模型不生成，而是两类 bug）：
1. **分镜只有景别、剧本只有角色名**——前端字段读取错误（读到的是 `shot_type`/`character`，而非 `desc`/`action`/`background`/`line`）
2. **prompt 太空泛**——未按「分层叠加法」填满六层（定调/场景/主体/动态/镜头/负向），模型只能自由发挥

**已修复**：
- 前端剧本：读取 `d.line || d.text || d.content || d.speech`，显示每集 `plot`/`scene`
- 前端分镜：读取 `desc || description` + `action` + `background` + `camera_movement` + `dialogue`，列名改为「画面描述」
- 后端 `script_agent`：按所选风格注入量化关键词；`_fill_script_defaults()` 兜底补全空 `line`
- 后端 `storyboard_agent`：prompt 按分层叠加法约束（scene/action/background/lighting/sd_prompt 具体化，禁空泛词，宁长勿空）；`_fill_shot_defaults()` 兜底生成 `desc` 摘要 + 负向词 + sd_prompt
- 强化「对白 line 绝不能为空」，后端兜底补台词
- 详见《[AI提示词模板_分层叠加法.md](AI提示词模板_分层叠加法.md)》

### 7. 风格 → 模型映射（可自定义 + 小白建议）
**已实现**：
- 配置中心 `config/config.yaml` 新增 `styles` 表，内置 4 套风格：**写实风格 / 二次元 / 水墨风 / 赛博朋克**
- 每套含：`llm_model`(文字模型) / `image_ckpt`(出图模型) / `image_model_type` / `description`(风格说明) / `advice`(小白建议·该换什么模型更好) / `recommended_models`(推荐列表) / `keywords`(注入关键词) / `neg_prompt`(负向词)
- 解析器 `config/style_resolver.py`：按「当前激活风格」读取 LLM 模型 / 出图 checkpoint / 关键词 / 负向词
- `OllamaProvider.__init__`：未显式指定模型时，自动用当前风格对应模型
- 接口 `GET /api/v1/pipeline/styles` 返回全部风格配置
- 前端：风格下拉动态加载 + 选择后显示「说明 / 建议 / 已配置模型」卡片；启动时把所选风格提交到后端

**使用/改法（给小白）**：
- 前端右上「写实风格 ▾」下拉即切风格，下方卡片会告诉你——当前这套用的是什么模型、想更好应该换什么、怎么换。
- 想自定义：改 `config/config.yaml` 的 `styles.<风格名>`，把 `image_ckpt` 改成你已下载的模型文件名即可（须在 ComfyUI 的 models/checkpoints 下）。

示例（写实风格）：
```yaml
写实风格:
  llm_model: "qwen3:8b"
  image_ckpt: "v1-5-pruned-emaonly.safetensors"
  advice: "想更像真人照片 → 用 SD1.5 写实底模（如 RealisticVision）最稳；若画面偏灰、细节糊，可换 FLUX.1-schnell（需 M4 用 Metal 加速）。"
  recommended_models: ["v1-5-pruned-emaonly.safetensors", "Realistic-Vision-V5.1.safetensors", "FLUX.1-schnell"]
```

### 8. 前端可改方案 / 剧本并提交
**已实现**：
- 管线运行到剧本阶段会触发 `script_approval` 审核断点 → 前端弹出「方案 + 剧本」编辑框（textarea，可改 JSON）
- 点击「💾 保存修改并继续」→ 调 `POST /api/v1/pipeline/submit/{pipeline_id}`，后端 `submit_edit` 覆盖当前快照 → 管线按新剧本继续
- 同时在 `storyboard_approval`（分镜）也做审核断点确认

### 9. 前端显示日志 / 运行情况
**已实现**：
- 前端底部「运行日志」面板：SSE 事件驱动实时追加，含时间戳 / Agent 标签 / INFO-SUCCESS-WARN-ERROR 颜色，新版日志在最上方，自动展开
- 进度条 + 7 卡片实时状态机 + 当前 Agent 提示（如「storyboard_agent 执行中…」）
- 抽帧/出图/视频等中间产出在详情区实时展示
