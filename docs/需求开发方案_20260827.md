# AIGC 需求开发方案（2026-08-27）

## 一、需求梳理（用户五大诉求）

### 1. 自动生成流程升级
**现状**：拿到需求直接进剧本 → 出图 → 视频，无前期资料收集与方案沉淀。
**目标**：需求 → 资料/素材收集 → 对比类似成品 → 输出完整制作方案 → 文案 → 分镜 → 出图 → 视频。
**实现**：
- 新增 `research_agent`（第 0 步）：基于需求用本地 Ollama 生成「制作方案」——目标人群、风格方向、叙事结构、渲染引擎关键词、光影关键词、参考片单，输出结构化方案 JSON。
- `script_agent` 增强：消费制作方案，文案按场景细分、植入关键词强调（渲染引擎/光影强化）。
- 渲染引擎/光影关键词（用户提供）作为「风格词库」注入出图 prompt：
  - 渲染引擎：UE5.3 Lumen 全局光照 / Nanite 虚拟几何体影视级资产 / Octane X 光谱光照 / Redshift RT 次表面散射 / V-Ray 6 物理相机
  - 光影强化：光线追踪反射 / 光线追踪柔和阴影 / 路径追踪

### 2. 前端生成卡顿（必须修复）
**根因**（已定位）：
- 前端 SSE 只监听 `agent_blocked/pipeline_done`，**未监听 `agent_start/agent_done`** → 管线在跑但卡片不动，用户以为卡死。
- 运行中的管线 `snapshot/latest` 为空（只返回已完成 checkpoint），轮询无反馈。
- 审核断点（分镜/定妆）需人工点「确认继续」，弹窗不显眼时表现为"卡住"。
**修复**：
- 后端：SSE 广播补全 `pipeline_start/agent_start/agent_done/agent_fail`；新增「按 pipeline_id 查运行状态」前端轮询。
- 前端：监听全部事件；运行中实时刷新状态；审核弹窗居中置顶 + 呼吸提示；生成按钮反馈（排队→执行→审核→完成状态机）。

### 3. 前端登录系统
- 数据库：沿用 **SQLite**（`storage/ai_drama.db`，零迁移），新增 `users` 表（用户名 + 密码哈希 + token）。
- 后端：`POST /api/auth/register`、`POST /api/auth/login`、`POST /api/auth/logout`、`GET /api/auth/me`；token 用 `secrets` 生成存库；受保护接口校验 `Authorization: Bearer <token>`。
- 前端：登录/注册页（覆盖全屏），登录后跳工作台；token 存 localStorage，所有请求带 token；未登录拦截。

### 4. 视频质量（音频 + 画面）
**4.1 音频缺失/太弱**
- 音量提升：BGM 0.28→0.38、环境音 0.055→0.12、配音 0.95→1.25，输出前限幅防爆（软削波）。
- 新增**场景音效层**：根据分镜内容程序合成（煎锅滋滋声=高频白噪声包络、雨声、风声、脚步、城市车流），按分镜时间轴插入。
- BGM 升级：程序合成增加多风格（温馨/激昂/悬疑/清新，按剧情情绪选择）；尝试从 `flac.music.hi.cn` 下载真人 BGM（网站有人机验证，需本地 Chrome CDP 真实浏览器操作，失败则回退程序合成）。
- 用户可自助：把下载好的音乐放入 `storage/music/`，管线优先使用。

**4.2 画面走形（人物/物品/场景一眼假）**
- 出图尺寸：SD 512 → **768**（hi-res fix 后 1024），细节更多。
- prompt 强化：分镜 `sd_prompt` 自动追加渲染引擎 + 光影关键词 + 摄影参数（35mm/f2.8/浅景深）。
- 角色一致性：已有 ControlNet(canny)+角色资产，提高 `controlnet_strength` 0.65→0.8，并保持 seed 稳定。
- 分镜细节确认：剧本阶段强制「每镜内容细节」字段（主体/动作/道具/光影/镜头），出图前可预览确认。

### 5. 工作方式
- 集中开发完毕 → 统一测试验证 → 修复 → 交付，不边开发边跑。

## 三、架构决策
- 数据库：SQLite（现有，零迁移）
- 认证：token（secrets 随机）存库，Bearer 头校验
- 音乐：`storage/music/*` 优先 → CDP 下载 → 程序合成回退
- 出图：保留 SD1.5（M4 性能），prompt/尺寸/ControlNet 优化；若质量仍不足，后续评估 SDXL-lite 量化版

## 四、集中测试验证（2026-08-27 凌晨）

### 验证结果
- ✅ **登录系统**：注册/登录/登出/me 接口全部通过；前端登录页（登录/注册 tab）经 agent-browser 实测登录成功（token 存 localStorage，顶栏显示用户名）
- ✅ **前端卡顿修复**：后端 SSE 广播事件全部补全（pipeline_start/agent_start/agent_done/agent_fail/agent_blocked/pipeline_done），前端全事件监听 + 4s 运行状态轮询
- ✅ **流程升级**：research_agent 产出完整方案（风格/渲染引擎/光影/文案要点/BGM情绪/场景声效）→ script 消费方案生成剧本
- ✅ **全管线跑通**：research→script→storyboard(10镜)→character(3角色)→image(10张768)→video(10段)→subtitle→compose→audio→publish，成片 36.24s、1024x1024、AAC 音频
- ✅ **音频增强**：情绪 BGM（温馨/激昂/悬疑/清新）+ 场景音效（煎锅滋滋/车流）+ 响度提升（max -17.2dB → -14.0dB）
- ✅ **出图质量**：768 尺寸 + 影视关键词注入（lumen/nanite/octane）+ ControlNet 0.8

### 测试中发现并修复的问题
1. **SSE 广播作用域 bug**：`_sse_broadcast` 定义在 register 函数内，模块级 `_execute` 访问不到 → NameError 管线崩溃。已提升到模块级
2. **Ollama 偶发坏 JSON**：qwen3:8b json 模式偶发输出单字符 `{` → script/storyboard 重试次数 3→5，重试间隔 8s
3. **num_predict 截断**：4096 → 8192（长剧本 JSON 被截断）
4. **resume 断点续传 bug**：`compose_agent` 在 AGENTS_PIPELINE 但无 checkpoint（已被 video_compose_agent 取代）→ 续传永远判不连续 → 全量重跑。已从 AGENTS_PIPELINE 移除
5. **手动重合成音频工具**：`scripts/re_audio.py` 可对现有成片单独重跑增强音频（不重跑全管线）
