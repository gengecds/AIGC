# AI 提示词模板：分层叠加法

> 来源：抖音「AIGC小悦儿」《新手写AI提示词总翻车？掌握分层叠加法，层层细化拿捏完美画面》
> 方法：把模糊的灵感翻译成 AI 能听懂的具体要素，层层叠加，收窄 AI 的自由度，实现精准、可控成图。

---

## 一、核心思路

新手写 AI 提示词「总翻车」的根源是：**提示词过于抽象、信息不完整，导致 AI 只能自由发挥**。「分层叠加法」像剥洋葱一样，把画面一层层拆解并叠加细化。

> 一句话：**先定整幅画面的「骨架/基调」，再逐层往里面填「血肉细节」，最后上「禁忌锁」。**

## 二、六大层次总览

| 层级 | 名称 | 作用 | 关键动作 |
|------|------|------|----------|
| ① | 定调画质 | 敲定画面整体调性、光影质感、艺术风格 | 对标具体的作品/风格模板 |
| ② | 细化场景 | 刻画具象视觉元素，提高还原度、拉满氛围感 | 把「背景」换成可被 AI 识别的具体描述 |
| ③ | 精雕角色 | 让主体立起来、有辨识度 | 把抽象词替换成具象细节 |
| ④ | 塑造动态 | 让画面有情绪和氛围感 | 明确状态 + 动态细节 |
| ⑤ | 把控镜头 | 拍出「高级感/专业感」 | 设定景别、构图逻辑、视角 |
| ⑥ | 副相约束 | 规避常见 bug、提升出图质量 | 设定绝不要出现的元素 |

## 三、六层通用填空模板

```
① 风格与画质：________ 风格，________ 光影，________ 画质
② 场景：在 ________ 环境下，有 ________、________ 等元素
③ 主体：________，________，________，________（具象细节）
④ 动态：正在 ________，表情 ________，姿态 ________，情绪 ________
⑤ 镜头：________ 景别，________ 视角，________ 构图，________ 景深
⑥ 负向约束：no ________, no ________, no ________
```

## 四、填写卡壳小技巧

- **① 想不到风格** → 直接抄你喜欢的作品/动画/电影名，如「宫崎骏画风」「韦斯·安德森配色」。
- **② 场景太空** → 加「时间 + 天气 + 光源」，氛围立刻上来（深夜 / 暴雨 / 逆光）。
- **③ 主体太抽象** → 把「漂亮」拆成「五官 + 发型 + 穿搭」三件套，AI 才认得。
- **⑤ 不会定镜头** → 记住最小组合：`景别 + 视角`，即可出高级感。
- **⑥ 副相约束** → 固定带上「畸形、多余手指、水印、模糊」这几个通用禁忌。

### 进阶技巧

- **肤质与光影**：想要「透亮感」加 `通透奶油肌，柔和光晕`；想要「高级冷感」加 `冷调低饱和，硬光，立体阴影`。
- **眼神与眼神光**：加 `眼神清澈，有明显眼神光`，往往决定一张人像的「气质」。
- **统一风格**：① 和 ③、④ 的「情绪」要一致——御姐配暖光慵懒、萌妹配清新活泼，别混搭。
- **面妆细节**（可选）：`淡妆，清透底妆，微翘睫毛`，能让面部更精致真实。
