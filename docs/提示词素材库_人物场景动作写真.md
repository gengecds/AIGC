## 一、写真风格万能模板（4 组，可直接复制）

### 1. 极简棚拍风（强调肤质与五官细节）

> 特点：背景干净，突出面部轮廓和皮肤真实纹理，适合头像/商业展示。

```
A stunning portrait of a young Asian woman, flawless skin texture, detailed pores, natural makeup, soft studio lighting, solid grey background, shot on Hasselblad X2D 100C, 85mm lens, f/2.8, ultra-high resolution, 8k, photorealistic.
```

### 2. 户外自然光风（强调氛围感与情绪）

> 特点：自然光（黄金时刻），画面有呼吸感，适合社交媒体分享。

```

```

> 中文释义：穿着飘逸白裙的美丽女性，走在阳光森林中，黄金时刻，树叶间斑驳阳光，风吹发丝，电影级光影，浅景深，背景虚化，索尼 A7R IV，35mm 镜头，色彩鲜艳，杰作。

### 3. 赛博朋克/夜景风（强调光影对比与时尚感）

> 特点：霓虹灯光、强对比度，适合潮流前卫写真。

```

```

> 中文释义：赛博朋克风美女肖像，面部反射霓虹灯光，未来感妆容，湿发，夜晚城市街道背景，下雨，体积光，光线追踪，超精细，4k，对焦清晰。

### 4. 复古胶片风（强调颗粒感与故事感）

> 特点：模拟老相机色彩、胶片颗粒，适合文艺情绪写真。


> 中文释义：复古胶片摄影，迷人女性坐在窗边看书，柔和自然光，柯达 Portra 400 胶片颗粒，暖色调，怀旧氛围，边缘微虚，高质量。

## 二、画质与真实感「魔法后缀」（任意风格通用）

> 无论哪种风格，末尾追加以下参数可显著提升出图质量。

| 类别 | 关键词 | 说明 |
|:--|:--|:--|
| 画质增强 | `8k resolution, ultra-detailed, photorealistic, RAW photo, masterpiece, best quality` | 提清晰度/质感 |
| 镜头模拟 | `85mm lens`（人像黄金焦段）`f/1.8`（大光圈虚化）`Hasselblad / Sony A7R IV / Leica`（高端相机色彩） | 模拟真实器材色彩 |
| 光影修饰 | `volumetric lighting`（体积光/丁达尔）`rim light`（轮廓光）`soft studio lighting`（柔光）`golden hour`（黄金时刻） | 提升光影层次 |
| 负面提示词 | `bad anatomy, bad hands, missing fingers, extra digits, blurry, deformed eyes, plastic skin` | 防崩坏手指/塑料感皮肤 |

### 常用参数设置（Midjourney 为例）

- 比例：`--ar 3:4`（手机壁纸/小红书）｜ `--ar 9:16`（抖音/朋友圈）｜ `--ar 1:1`（头像）
- 风格化：`--s 250-500`（写实建议区间，越高艺术感越强）
- 真实感：`--style raw`（减少 AI 默认美化，皮肤更真实）

## 八、组合公式（核心总结）

```
万能公式 = 主体（人物/服装/妆容）
         + 场景（环境+时间+天气+光源）
         + 动作姿态（动作+表情+情绪）
         + 摄影参数（镜头+光圈+景别+构图）
         + 画质后缀（8k, photorealistic, masterpiece...）
         + 负面提示词（bad hands, plastic skin...）
```

**示例组合（赛博朋克御姐）**：
```
Cyberpunk portrait of an elegant woman, black leather jacket, smoky eye makeup, wet hair,
neon-lit night street, rain, rim light, volumetric lighting, 85mm lens, f/1.8, shallow depth of field,
medium shot, low angle, ultra-detailed, 8k, photorealistic, masterpiece
Negative: bad anatomy, bad hands, extra fingers, blurry, plastic skin
```
