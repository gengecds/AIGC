## 二、6 步生产流程 · 端到端链路图

```
用户输入一句话/大纲/题材
    ↓
Step 1: 情报站 + DeepSeek 生成文案/剧本
    ↓
【前端：剧本编辑器 + 审核弹窗】← 修改/重生成
    ↓ 确认
Step 2: DeepSeek + Skills 拆分镜
    ↓
【前端：分镜表格编辑器】← 改某行 / 重生成某行
    ↓ 确认
Step 3: 分镜 + Skills → ComfyUI（SD/FLUX）批量出图
    ↓
【前端：图片网格 + 单张重生成 + 审核】
    ↓ 确认
Step 4: 确认后的分镜图 + Skills(运镜/题材) → ComfyUI MiniMax H3 → 视频片段(含原生音频)
    ↓
Step 5: 增强版 FFmpeg 合成（转场 + 色彩 + 音频动态压缩 + 字幕烧录）
    ↓
Step 6: 前端成片预览 + 下载导出
```

> \[!WARNING]
> 全程**所有「确认」步骤**都抛 `ReviewBlock` 异常（scheduler.py L74 已有类定义），Pipeline 暂停并落盘 checkpoint；前端 POST `/pipeline/continue` 或 `/pipeline/override`（带修改后数据）后再恢复执行。

### Step 5 · 拼接成品 · 增强版 FFmpeg 合成（方案 A，推荐先做）

| 项        | 内容                                                                                                                                                                                                                    |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **输入**   | Step 4 的视频片段列表 + SRT 字幕 + 可选配音/BGM                                                                                                                                                                                    |
| **后端链路** | `VideoComposeAgent` 里改 FFmpeg 命令链：① 每段加 0.4s 淡入淡出 → ② 片段间 0.3s dissolve xfade 叠化转场（同时 acrossfade 音频）→ ③ 视频色级微调 colorgrade → ④ 字幕烧录 force\_style 指定 PingFang SC 字体 + 描边样式 → ⑤ 音频 acompressor 动态压缩（防炸音提响度）→ ⑥ 如有独立配音轨混音 |
| **输出**   | `final_video.mp4`（编码 h264 / AAC 160k，9:16 竖屏 720×1280 或 16:9 横屏 1280×720）                                                                                                                                             |
| **代码改动** | ① 把现在的裸 `ffmpeg concat demuxer` 替换成以下增强版命令                                                                                                                                                                            |

```bash
# 伪代码：FFmpeg 增强合成链路（VideoComposeAgent 里重写）
# ① 先给每段做 fade + 分辨率强制统一 + 色级微调
for i, seg in enumerate(segments):
    dur = seg.duration
    ffmpeg -i seg.mp4 \
      -vf "fade=t=in:st=0:d=0.4,fade=t=out:st=${dur-0.4}:d=0.4,
           scale=720:1280:force_original_aspect_ratio=decrease,
           pad=720:1280:(ow-iw)/2:(oh-ih)/2,setsar=1,
           colorgrade=contrast=1.05:saturation=1.08" \
      -af "afade=t=in:st=0:d=0.4,afade=t=out:st=${dur-0.4}:d=0.4,
           acompressor=threshold=-18dB:ratio=4:attack=5:release=50:makeup=2dB" \
      -y seg_fade_${i}.mp4

# ② xfade 叠加拼接（递归串 xfade + acrossfade filter）
# 输出：final_no_sub.mp4
# ③ 烧录字幕
ffmpeg -i final_no_sub.mp4 -vf "subtitles=final.srt:\
  force_style='FontName=PingFang SC,FontSize=26,PrimaryColour=&H00FFFFFF,\
  OutlineColour=&H00000000,BorderStyle=1,Outline=2,Shadow=0,MarginV=60,Alignment=2'" \
  -c:v libx264 -preset medium -crf 22 -pix_fmt yuv420p \
  -c:a aac -b:a 160k -shortest -y final_video.mp4
```

> \[!TIP]
> 「剪映质感」的关键不是拼剪映，是这 **4 个滤镜**：fade 淡入淡出 × xfade 叠化 × colorgrade 色级 × acompressor 响度压缩。成本 0，效果能从 60 分 → 80 分。

### 5.2 缺口：语音克隆（clone）功能

第一个抖音视频强调的「语音克隆」是**上传一段参考音频复刻音色**，现在 audio\_tools.py 里只有「音色设计」（用文字描述生成新声音），没有 clone。需要补一个函数：

```python
# 在 providers/audio_tools.py 末尾新增（参考官方 VoxCPM CLI clone 命令）
def clone_voice(text: str,
                 reference_audio_path: str,
                 output_path: str,
                 style_prompt: str = "",
                 reference_transcript: str = "",
                 device: str = "auto") -> float:
    """VoxCPM2 语音克隆：上传 3-10s 参考音频 → 复刻该音色读 text
    视频里「离谱的语音克隆」就是这个能力。
    """
    model = _get_vox(device)  # 复用现有懒加载
    audio = model.generate(
        text=text,
        reference_audio=str(reference_audio_path),        # 关键：传参考音频
        reference_transcript=reference_transcript or None,
        style_prompt=style_prompt or None,
        cfg_value=2.0,
        inference_timesteps=10,
        normalize=True,
    )
    audio = np.asarray(audio, dtype=np.float32).reshape(-1)
    if audio.size == 0:
        logger.warning("[TTS:voxcpm_clone] 输出空，回退 Piper 保底")
        return _synthesize_piper(text, output_path)
    # 以下重采样+保存逻辑和 _synthesize_vox() 完全一致
    src_sr = int(getattr(model.tts_model, "sample_rate", 48000))
    audio = _resample_float32(audio, src_sr)
    pcm = (np.clip(audio, -1.0, 1.0) * 32767).astype(np.int16)
    with wave.open(output_path, "wb") as wf:
        wf.setnchannels(1); wf.setsampwidth(2); wf.setframerate(SAMPLE_RATE)
        wf.writeframes(pcm.tobytes())
    return len(pcm) / SAMPLE_RATE
```

## 七、DeepSeek Provider · 接入步骤

你代码里 `providers/llm.py` 只有 `OllamaProvider`，缺 `DeepSeekProvider`。新增类 \~60 行：

```python
# providers/llm.py 末尾追加
class DeepSeekProvider(LLMProvider):
    """DeepSeek Chat API（OpenAI SDK 兼容）。
    环境变量 DEEPSEEK_API_KEY 必填，写在 .env 里，不要硬编码。
    """

    BASE_URL = "https://api.deepseek.com/v1"
    DEFAULT_MODEL = "deepseek-chat"

    def __init__(self, api_key=None, model=None):
        import os
        self.api_key = api_key or os.environ.get("DEEPSEEK_API_KEY", "")
        if not self.api_key:
            raise RuntimeError(
                "未设置 DEEPSEEK_API_KEY。请在 .env 里配置；绝对不要把 Key 硬编码进代码或提交 git。"
            )
        self.model = model or os.environ.get("DEEPSEEK_MODEL", self.DEFAULT_MODEL)
        self._client = None  # 懒加载

    def _get_client(self):
        if self._client is None:
            from openai import AsyncOpenAI
            self._client = AsyncOpenAI(api_key=self.api_key, base_url=self.BASE_URL)
        return self._client

    async def generate(self, prompt, system_prompt=None, model=None, **kwargs):
        return await self.chat(
            messages=[
                {"role": "system", "content": system_prompt or ""},
                {"role": "user", "content": prompt},
            ], model=model, **kwargs,
        )

    async def chat(self, messages, model=None, **kwargs):
        is_json = bool(kwargs.get("json_mode"))
        params = dict(
            model=model or self.model,
            messages=messages,
            temperature=kwargs.get("temperature", 0.3 if is_json else 0.7),
            max_tokens=kwargs.get("max_tokens", 8192),
        )
        if is_json:
            params["response_format"] = {"type": "json_object"}
        client = self._get_client()
        timeout = kwargs.get("timeout", 600)
        resp = await client.chat.completions.create(timeout=timeout, **params)
        return resp.choices[0].message.content
```
