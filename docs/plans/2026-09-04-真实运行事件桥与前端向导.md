# 2026-09-04 · 真实运行 → 5 步向导事件桥（主线推进记录）

> 开发目标：让「前端 5 步向导」不再只看 __demo__ 假数据，能实时看到/恢复真实管线运行的每一步审核内容。

## 背景

存在两套 SSE：真实管线广播 `agent_*` 事件到 `/api/v1/pipeline/events/stream`；而 5 步向导只订阅 `/pipeline/events?run_id=xxx`（pipeline\_events\_router）。真实管线从不向后者发事件 → 向导只能看 __demo__。

## 改动

### 1) 后端 `api/routes/pipeline.py`：真实运行 → 向导事件桥

- 顶部 import `publish_pipeline_event`（无循环依赖）。

- 新增 `_wiz_*` 帮助函数：

  - `_wiz_step_of(agent)`：agent→步骤0-4（research/script→0；storyboard→1；character/image→2；video/subtitle→3；compose/audio/publish→4）。

  - `_cp_data(agent)` 读 checkpoint 内层 data（容错）。

  - `_fmt_script()` 结构化剧本→纯文本；`_char_rows()` 角色→向导行。

  - `_first_media()`/`_wiz_media_url()` 路径→`/comfyui-output`、`/storage/output` URL。

  - `_wiz_payload(agent)` 各 agent 数据 → 与 demo 同构 payload；出图节点沿用已确认角色卡，避免覆盖。

  - `_wiz_publish()` / `_final_wizard_payload()`。

- `_execute()` 回调补发布：on\_start（无 payload 进行中事件）、on\_review（步骤真实内容 payload，percent=(step+1)\*20）、on\_fail/顶层异常（error）、on\_done（先 step4 成片 payload 再 done）。

- `run_pipeline` 启动补「🚀 管线已启动」。

### 2) 前端 `PipelineView.vue`：支持真实 run\_id

- `?run_id=` 参数读真实 run\_id，缺省 `__demo__`；`sseUrl()` 动态拼地址。

- 「真实创作运行栏」：一句话 + 风格下拉 + 开始（POST /run）+ 恢复进行中（GET /active）。

- `handleProgressEvent` 加「payload 需带内容」守卫，防止进行中事件提前点亮空步骤。

- 新增 `resetRunState()` 防真实/演示串场。

## 追加 3 · 生图工作流导出（ComfyUI 画布 JSON 复用）

需求：把代码动态构造的 ComfyUI「API 工作流」转成能拖进 ComfyUI 网页的画布 JSON，供查看/调整/复用。

### 改动

- 新增 `providers/comfyui/workflow_templates.py`：

  - `api_workflow(kind)` 用真实 builder 生成 4 类模板（sd15/flux/controlnet/ipadapter）的 API 格式；

  - `api_to_ui()` 把 API 格式转成 ComfyUI **画布(UI)格式**（nodes/links/坐标/每类节点槽位白名单 + 简单分层排版），与执行代码同源不漂移。

- 新增 `api/routes/comfyui_router.py`（已在 main.py 挂载）：

  - `GET /api/v1/comfyui/workflows` 模板清单；

  - `GET /api/v1/comfyui/workflows/{kind}?format=ui|api&download=1` 返回 JSON（默认画布格式）。

- 前端 index.html：顶栏新增「工作流」抽屉按钮 → 列出 4 类模板，每张卡片可「下载画布 JSON / 下载 API JSON」。

### 验证

- 4 模板 api→ui 转换：节点数与链接一致、无坏链（sd15=7节点/9链，flux=9/9，controlnet=10/12，ipadapter=13/15）。

- 后端接口返回 200、可下载、JSON 可解析。

- 用法：下载后把画布 JSON 拖进 ComfyUI（或 Workflow→Open）即可查看/改提示词与参数；改完 Ctrl+S 另存为自己的模板。
