## 一、生图提示词 · 万能公式（速查）

```
① 主体：人物/服装/妆容（五官、发型、穿搭，越具体越稳）
② 场景：环境 + 时间(黄金时刻/深夜) + 天气(雨/雪/雾) + 光源(逆光/体积光)
③ 动作姿态：动作 + 表情 + 情绪
④ 摄影参数：镜头(85mm人像黄金焦段) + 光圈(f/1.8大光圈虚化) + 景别(特写/半身/全身) + 构图
⑤ 画质后缀：8k, ultra-detailed, photorealistic, masterpiece, best quality
⑥ 负面提示词：bad anatomy, bad hands, missing fingers, plastic skin, blurry
```

**分层叠加法六层**（AIGC小悦儿）：①定调画质 → ②细化场景 → ③精雕角色 → ④塑造动态 → ⑤把控镜头 → ⑥负向约束。填卡壳时：风格抄作品名、场景加时间/天气/光源、主体拆三件套（五官+发型+穿搭）、镜头最小组合「景别+视角」。

**词库索引**（详见素材库文档）：
- 人物：五官/发型/服装/妆容气质（中英对照）
- 场景：12 类（森林/海边/老城/霓虹夜街/雪景/樱花…）
- 动作：12 种（回眸/撩发/倚窗/旋转裙摆…）
- 风格：16 种（日系/港风/新中式/Y2K/赛博朋克/废土/哥特…）
- 摄影：焦段/光圈/景别/构图/轮廓光

## 二、生视频提示词 · 电影级运镜（速查）

5 种一镜到底运镜（VibePaper），完整原文见分层叠加法文档第十四章：

| 运镜 | 一句话技法 | 适用 |
|:--|:--|:--|
| ① 诺兰时间操控 | FPV 超现实长镜头：贴地冲刺→天井下坠→重力倒置→镜像世界 | 科幻梦境/时间错乱 |
| ② 贝式英雄镜头 | 低角度贴地仰拍 + 逆时针 180° 上升环绕 + 逆光剪影 + 青橙色调 | 超级英雄出场 |
| ③ 斯皮尔伯格镜头 | 三段式：0-4s 移焦悬念 / 4-9s 过肩跟拍 / 9-15s 180° 环绕冷蓝 | 悬疑叙事 |
| ④ 克里斯托弗·诺兰 | 沙漠史诗：航拍俯冲→贴地环绕→侧脸特写→史诗大远景，青橙LUT | 史诗开篇 |
| ⑤ 希区柯克变焦 | 轨道车推进 + 焦距反向拉远，人物恒定、背景透视撕裂 | 真相揭晓瞬间 |

**视频生成要点**：
- 本机 LTX-Video：512×512 约 2-4 分钟/段；768×512（正式用）5-15 分钟/段
- 镜头时长：真人广告节奏 3.5-5.2 秒/段（88-129 帧 @25fps），太短显"AI 味"
- ③ 分段式适合支持多镜头时间线的工具；①④ 篇幅长可截核心段试跑

## 三、本机引擎选择（生成时选什么跑）

> 核心约束：**M4 无 NVIDIA GPU → 无 CUDA**。标注「GPU 24G+」的模型一律避开。

| 任务 | 用这个（✅ 本机可用） | 别用（⚠️ 跑不了） |
|:--|:--|:--|
| 图片生成 | SD1.5 (v1-5-pruned) · SDXL (RealVisXL-V4.0) · z-image-turbo | FLUX.1（无CUDA+dev禁商用） |
| 视频生成 | LTX-Video 2B（官方支持 MPS） | MiniMax H3（需 24G 显存） |
| 本地 LLM | Ollama qwen3:8b（24GB 内存正合适） | Qwen 27B（超内存） |
| 文字转语音 | Piper TTS · VoxCPM2（已下载） | — |
| 语音转录 | FunASR + SenseVoice（已装） | — |
| OCR | macOS Vision（swift 脚本，零依赖） | PaddleOCR（py3.14 无包） |
| 视频合成 | FFmpeg（转场/调色/字幕/遮幅） | — |

**模型位置**：出图模型在 SD-WebUI 目录（ComfyUI 共享）；LTX 模型在 ComfyUI-Shared/diffusion_models；qwen3:8b 在 Ollama。详见部署方案附录 K。

## 四、一句话记忆

- **生图**：主体+场景+动作+摄影+画质+负面 = 六件套；写实加 `photorealistic, 8k, 85mm, f/1.8`
- **生视频**：套 5 种运镜原文；LTX 用 8 步/512×512 先验证
- **引擎**：图用 SD1.5/SDXL，视频用 LTX，别碰需 CUDA 的模型
